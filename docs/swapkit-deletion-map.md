# SwapKit app-code deletion map (T9, swapkit#88)

As the server work-packages (WP1–WP15, issue nuri-com/nuri-mcp-bitcoin-swapkit#88) land, the
app shrinks toward "quote → create → one send → display". This maps each app-side swap
mechanism to the server WP whose shipping makes it deletable. File paths verified against this
branch (feat/arkade-vhtlc-phase-2, working tree of 2026-07-16 — parallel lanes T2/T7 are
editing some of these files right now).

Phases: **A** = no custody change (WP1–6), **B** = delegated pre-signed claims (WP8–12),
**C** = EVM legs server-executed (WP13–15).
