# Nuri 0.96.2: clearer payment links

Web release candidate for app.nuri.com. Issue #1185; PR #1186 against dev.

Public /pay/@username links keep the chosen asset, exact amount and recipient visible. The confirmation now shows a shortened recipient address above the QR and only “Tap to copy” below. Copying retains the complete payment request, including source chain, token and amount. Bitcoin and Lightning targets also offer OS wallet handoff.

Existing Bitcoin, Lightning, Arkade, USDC Base, EURC Base and USDC Arbitrum rails remain. New Wirex deposit APIs, Confidential routes and WalletConnect runtime are not included. The deployed 0.96.1 Home and Support changes are preserved; Support identifies this loaded JavaScript release as 0.96.2.
